REA Unlock DPC

Device-Owner-Fallback für das Pixel 7a.

- `apk/rea-unlock-dpc.apk` – signiert, Paket `com.rea.unlockdpc`
- `qr/rea-dpc.png` – Provisioning-QR
- `apk/rea.keystore` – Signaturschlüssel, Passwort `rearea`

Der DPC setzt als Device Owner `adb_enabled=1` und `adb_wifi_enabled=1`.

Download-URL im QR: `https://raw.githubusercontent.com/MoodTechBasti/pixel7a-unlock/main/apk/rea-unlock-dpc.apk`
